One line: the error message an AI agent shows when it runs out of tokens mid-sentence. Instead of describing the outage, the line demonstrates it -- it dies mid-word, right where the tokens ran out, so the reader watches the failure happen instead of being told about it.

> I'm not ghosting you, I just ran out of tokens mid—

Run it with `python3 main.py` (writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, default `/output`, as bytes with no trailing newline).
